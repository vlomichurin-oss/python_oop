# Лабораторная работа №2: Коллекция объектов StudentCollection
**Коллекция** — это объект-контейнер, предназначенный для хранения, управления и доступа к группе других объектов (элементов) в единой структуре.
## Цель работы

* Научиться работать с **коллекциями объектов**.
* Понять разницу между **моделью сущности и контейнером объектов**.
* Реализовать **собственный контейнерный класс**.
* Освоить **итерацию по объектам**.
* Реализовать базовые операции управления коллекцией.

# Collection.py

## Базовые методы

* `add(player)` - Добавляет игрока в коллекцию. Вызывает ошибку при дубликате никнейма
* `remove(player)` - Удаляет указанного игрока
* `remove_at(index)` - Удаляет игрока по индексу и возвращает его
* `get_all()` - Возвращает копию списка всех игроков

## Поиск

* `find_by_nickname()nickname` - Поиск игрока по никнейму
* `find_by_class(player_class)` - Возвращает список игроков указанного класса

## Сортировка

* `sort_by_level(reverse=False)` - Сортировка по уровню
* `sort_by_nickname(reverse=False)` - Сортировка по никнейму(алфавитно) 

## Фильтрация 

* `get_alive` - Возвращает новую коллекцию с живыми игроками
* `get_by_class` - Возвращает новую коллекцию с игроками указанного класса

## Магические методы

* `__len__` - Возвращает количество игроков
* `__iter__` - Позволяет итерировать коллекцию
* `__getitem__` - Доступ по индексу
* `__str__` -  Строковое представление
