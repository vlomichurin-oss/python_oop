* Понять концепцию паттерна «Стратегия» и реализовать его на Python.
* Освоить `lambda`-выражения и их практическое применение.

## 2. Реализованные функции и стратегии

### Функции-стратегии для сортировки

- `by_nickname(player)` — сортировка по никнейму в алфавитном порядке
- `by_level(player)` — сортировка по уровню персонажа
- `by_health(player)` — сортировка по количеству здоровья
- `by_power(player)` — сортировка по силе (учитывает класс)
- `by_class_then_level(player)` — сортировка сначала по классу, затем по уровню

### Функции-фильтры

- `is_high_level(player, min_level=5)` — отбор игроков с уровнем выше порога
- `is_healthy(player, min_health=50)` — отбор игроков с здоровьем выше порога
- `is_warrior_or_mage(player)` — отбор воинов и магов
- `is_alive_filter(player)` — отбор только живых игроков

### Фабрики функций

- `make_level_filter(min_level)` — создаёт фильтр по минимальному уровню
- `make_health_filter(min_health)` — создаёт фильтр по минимальному здоровью
- `make_experience_filter(min_exp)` — создаёт фильтр по минимальному опыту
- `apply_discount_to_power(discount)` — создаёт функцию применения скидки к силе

### Паттерн Стратегия и callable-объекты

**Паттерн Стратегия** определяет семейство алгоритмов, помещает каждый в отдельный класс и делает их взаимозаменяемыми. Это позволяет выбирать алгоритм во время выполнения без изменения кода коллекции.

**Callable-объекты** — классы с методом `__call__`, которые можно вызывать как функции. Они могут хранить внутреннее состояние.

- `PowerBoostStrategy(boost_percent)` — стратегия усиления силы на процент. Вызов возвращает новую силу.
- `HealStrategy(heal_amount)` — стратегия лечения. Вызов восстанавливает здоровье и возвращает количество вылеченных HP.

### Методы коллекции

- `sort_by(key_func, reverse=False)` — сортировка по стратегии
- `filter_by(predicate)` — фильтрация по предикату
- `map_to(transform_func)` — преобразование элементов
- `apply(func)` — применение функции ко всем элементам

## 4. Вывод

### Передача функций как аргументов

Функции являются объектами первого класса, что позволяет передавать их в другие функции и методы. Это было продемонстрировано при передаче стратегий сортировки (`by_level`, `by_nickname`) и фильтров в методы коллекции.

### Lambda, map, filter

Освоено использование встроенных функций высшего порядка:
- `lambda` — для создания анонимных функций в одну строку
- `map()` — для преобразования всех элементов коллекции
- `filter()` — для отбора элементов по условию

### Функции высшего порядка и замыкания

Реализованы фабрики функций, которые создают и возвращают новые функции с "запомненными" параметрами. Это демонстрирует механизм замыканий.

### Паттерн Стратегия

Реализован поведенческий паттерн «Стратегия» двумя способами:
- **Через функции** — передача именованных функций как стратегий сортировки и фильтрации
- **Через callable-объекты** — классы с методом `__call__`, которые хранят внутреннее состояние

Такой подход делает код гибким и расширяемым: стратегии можно легко заменять без изменения кода коллекции.
